## 🌍 What Is This? (English)

**Game Mechanics Vault** is a structured, interconnected knowledge graph of **139+ core game mechanics** across **28 game design domains** (Combat, Level Design, Enemy AI, Diegetic Guidance, Shaders & VFX, Economy, Rollback Netcode, and Anti-Patterns), distilled from industry postmortems and technical analyses.

Every mechanic page uses a strict **4-Bucket Architecture**:
1. **Theory & Heuristics** — Cognitive psychology, design intent, and systemic rules.
2. **Engine & Code (UE5 / Unity 6 / Godot 4)** — Concrete component names and numerical parameter tables (Floats, Curves, Raycasts, Frame Windows).
3. **Game Juice & Sensory UX** — Hitstop durations, trauma screenshake, SFX cues, and shader rim highlights.
4. **Anti-Patterns & Failure Modes** — Common traps, tautologies, and edge cases to avoid.
